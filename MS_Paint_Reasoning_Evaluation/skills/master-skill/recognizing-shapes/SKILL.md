## Purpose
This master skill provides protocols and visual references for recognizing common geometric and irregular shapes in images. Use this file to select the correct example image for the shape you need to identify or describe.

## Recognition Protocol

Step 1: Identify the shape in the image.
- Compare the target region to the example images in the routing table above.
- Use geometric properties (edges, angles, symmetry, aspect ratio) to match the shape.

Step 2: Reference the example image for the identified shape.
- When reasoning or answering, always cite:
	- This master skill file
	- The specific example image used

Step 3: Describe the shape using standard terminology.
- For geometric shapes, use terms like circle, square, triangle, etc.
- For irregular shapes, describe distinguishing features (e.g., number of lobes, symmetry, convexity).

Step 4: If the shape is ambiguous, compare to multiple example images and explain reasoning. If its not a clear match to any example, state its an "irregular" shape with "x" points and "y" edges.

## Example Shape Descriptions

- **Circle:** All points equidistant from center; no corners or edges.
- **Square:** Four equal-length sides, four right angles.
- **Rectangle:** Four sides, opposite sides equal, four right angles.
- **Triangle:** Three sides, three angles; can be equilateral, isosceles, or scalene.
- **Star:** Points radiating from center; typically five or more points.
- **Heart:** Two rounded lobes at top, pointed bottom.
- **Lightning:** Jagged, zigzag shape; often with sharp angles and asymmetry.
- **Irregular Shape:** Does not match any standard shape; describe number of points and edges.
